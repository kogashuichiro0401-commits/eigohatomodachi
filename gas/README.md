# 掲示板と編集版の保存先(Google スプレッドシート)の準備

利用者サイトの「掲示板」と「編集版“英語は友達”」の投稿は、Google スプレッドシートに保存します。
スプレッドシートに付けた Apps Script(`Code.gs`)が、サイトとのやりとりの窓口になります。

## 1. スプレッドシートを作る

1. Google ドライブで、新しいスプレッドシートを作ります(名前は自由です)。
2. メニューの「拡張機能 → Apps Script」を開きます。
3. 最初からある `コード.gs` の中身を全部消して、このフォルダの `Code.gs` の中身を貼り付け、保存します。
4. 上の関数の選択欄で `setup` を選び、「実行」を押します。
   - 初回は権限の確認が出ます。自分のアカウントを選び、「詳細 → (安全ではないページ)に移動 → 許可」と進みます。
   - スプレッドシートに「編集版」「スレッド」「書き込み」の3枚のシートができます。

## 2. ウェブアプリとして公開する

1. Apps Script の右上「デプロイ → 新しいデプロイ」を押します。
2. 種類の歯車から「ウェブアプリ」を選びます。
3. 次のように設定して「デプロイ」を押します。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 表示された「ウェブアプリの URL」(`https://script.google.com/macros/s/…/exec`)をコピーします。

## 3. サイトに URL を入れる

`index.html` の CONFIG の `gasUrl` に、コピーした URL を入れます。

```js
gasUrl: "https://script.google.com/macros/s/…/exec"
```

空のあいだは、サイトは見本データを表示します(送信はできません)。

## 管理のしかた

- **書き込みを消す**: その行の「非表示」にチェックを入れます。掲示板では「このレスは削除されました」と表示され、番号はずれません。行そのものは消さないでください。
- **スレッドを消す**: 「スレッド」シートの、その行の「非表示」にチェックを入れます。
- **Code.gs を直したとき**: 「デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新しいバージョン → デプロイ」で反映します。URL は変わりません。

## しくみの決まり

| 項目 | 内容 |
| --- | --- |
| 連続書き込み | 同じ端末からは30秒あける |
| 全体の上限 | 1分あたり30件 |
| 1スレッドの上限 | 1000レス |
| 名前 | 空欄なら「名無しさん」 |
| ID | 端末ごと・1日ごとに変わる8文字 |
| 文字数 | ニックネーム・名前 30、改善ポイント 600、タイトル 60、本文 1500 |
